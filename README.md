# keybordOnbord

Frontend: Next.js (React)
Backend: Go

## Structure
- frontend/  Next.js app
- backend/   Go API

## Frontend

Install and run:

```bash
cd frontend
npm install
npm run dev
```

## Backend

Run the Go server:

```bash
cd backend
go run .
```

Health check:

```bash
curl http://localhost:8080/healthz
```
